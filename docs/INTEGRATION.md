# 智见接入说明：0.2.0 → 0.3.0

本次为领域编排与平台接收契约升级。没有训练模型、刷新历史快照或修改 ACTIVE。用户最新指示覆盖旧接入方案的 §5 报告分层和 §6 L4/L5：四报告检查通过直接一起交付，不加角色权限和人工签核条件；既有平台登录、服务鉴权照常。

## 接受的反馈与修正

| 智见反馈 | 本版处理 |
|---|---|
| manifest 编译注册能力，任务级白名单 | 接受；提供六项 v2 技术 ID，各任务显式 allowedCapabilities；平台仍需编译绑定 |
| 运行资源只读挂载，暂不转换 SQLite | 接受；冻结目录保持原状，训练在本地；历史数据不塞入 LLM 上下文 |
| 四 DOCX 原件取回及 SHA256 校验 | 接受；异步 job、双端校验、任务附件通道 |
| 四报告为价格/租金/收益/收购 | 纠正：价格完整/外发、租金完整/外发；收益独立 |
| v1.1.0 已部署等同冻结 v2 | 不接受；必须核验独立运行包和资源 manifest |
| 生成报告 readOnly=true | 纠正为创建任务/产物操作；保持幂等 |
| 完整版内部角色、外发版人工批准 | 按最新需求取消；同一任务直接返回四份 |
| Noto 替代原仿宋 | 不默认替换；冻结字体环境须匹配，缺字体时不能假报视觉通过 |
| 原 Markdown→DOCX 生成链 | 不用于四报告；冻结生成器直接产 DOCX |
| 20MiB 文件经16MiB Provider响应 | 改用文件通道，JSON仅小型元信息；文件上限由平台确认 |

## 平台实施顺序

1. 安装本 Git 版本及完整 Skill/reference，登记新 Scenario、Team、Output、Quality 和优先路由。组合意图必须优先于价格/租金子串；明确“只要价格/租金”保留单业务，收益请求独立。边界说明不抢占正常估值报告路由。
2. 从伙伴私有交付入口 `exports/platform_asset_releases/` 接收运行 sidecar，与 `demo/fuzhou-runtime-reference.json` 对照 SHA256。领域 Git 不含该大文件。解压到独立版本目录，模型/特征/历史快照只读挂载，案例输出挂载到独立可写目录。
3. 使用运行包 START_HERE 的 `verify-release`、`validate-installation` 验证；记录实际 runtime/model/feature/history/template/generator 版本和全 hash。训练 feature_snapshot_version 与导出版本分开保留。Docker/linux/amd64 目标环境尚需真实验收，不能把已有本地测试当作容器测试。
4. 平台开发者在已有 rongcheng Provider 中注册六项 v2 能力并实现端点、异步任务与原始文件下载桥接。`v2-capabilities.json` 是约定清单，不能直接当作已编译平台插件。实际固定 URL 由平台配置；`/health`、`/models/active`、`/releases/active` 必须反映真实资源，不能继续回报旧 v1.1.0 冒充 v2。
5. 将质量规则绑定真实生成器检查及平台下载检查，保存回执。检查通过即返回四个任务文件链接，不等待批准。不能只修改文案却继续用旧 approved_for_external_delivery=false 阻断。
6. 完成黄金 Demo 与新案 live smoke、Provider bridge 回归，刷新 report snapshot 后重新生成四报告；旧 Markdown 报告不等于本版报告。

## 福州验收边界

冻结包价格有效月 2026-06、租金 2026-07；Demo 不是实时市场数据。包内的原始 release/lineage 不因四报告工具包称 v2 而改名。黄金样例参考输出：价格单价 15944.264013303165 元/㎡，月租 3151.4296586906794 元；同环境按工具包验收容差检查。

冻结模板保留仿宋、Word 原生公式；价格8公式、租金1公式，单文件5节，完整11表、外发8表。字体需合法来源且版本匹配，不接受静默字体替换。目标平台无 LibreOffice 时，在生成器容器渲染验收并保留证据，不能只靠 python-docx 重读声称视觉通过。

已知限制：冻结 v2 尚未包含本地随后修复的7月可比索引问题。稳定黄金 Demo 可先接；新案必须回归该问题，必要时另发补丁资源版本与新哈希，不修改冻结 v2 原件、不称任意新案已验证。

初版直接用原快照文件。以后平台需要 market-data PostgreSQL 或 localdb 时，导入派生副本并核对字段、行数、抽样查询；不要求先转换数据库才能演示，不改变本次源快照。

## 验收回填

提供实际安装 commit/release/hash、六项能力注册清单、真实调用审计、资源清单、同案四文件角色和 SHA256、生成器检查与字体环境渲染回执。反例至少包括：未覆盖城市、必填字段缺失、错案、旧 attempt、生成失败、少件/重复角色、下载被改、外发版未删减。四份齐全且质量通过时，无 approval/role 字段也应交付成功。

现阶段本地静态测试不能证明平台线上注册或服务已可用。

## 三类业务影响

- 服务商侧：提供通用四报告入口及可重复的福州 Demo；需要更新 Provider 和任务文件通道。
- 可部署客户侧：复用领域包；各实例需安装对应城市私有资源和服务配置，无新增报告角色分层。
- 估值咨询报告模块：冻结模板直接输出四原件并保留两种内容版本；银行 v14 暂不纳入本次变更。
