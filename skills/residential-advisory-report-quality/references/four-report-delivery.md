# 四报告交付规则

完整／外发区分内容，不区分领取角色。质量校验通过后向当前任务用户直接展示四份文件；不要求额外批准、专业签核或报告角色授权。保留平台既有登录和服务鉴权，不创建公网免鉴权下载地址。

四份文件严格为 `price_full`、`price_external`、`rent_full`、`rent_external`。持有收益及收购价不属于这四份。只返回摘要、只有两份、四份中角色重复，均不算完成。

四报告入口优先采用 residential-four-report-delivery。显式只要价格或只要租金可走原单业务；普通住宅估值、价格加租金默认四份。咨询性质说明不应变成报告下载审批。
