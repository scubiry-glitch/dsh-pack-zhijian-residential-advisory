# 确定性计算边界

## 必要输入

- 有效的市场价值参考结构化快照；
- 有效的租金参考结构化快照；
- 空置、运营费用、税费、持有期、折现率、退出收益率和退出费用；
- 每项假设的来源、单位、基准日和用户确认状态。

## 执行规则

1. 校验两个输入快照的标的、基准日和版本；
2. 调用确定性持有收益与收购价测算能力；
3. 保存全部输入、公式或规则版本、`calculation_snapshot_id`；
4. 分层解释基础、压力及其他已配置情景；
5. 缺项时返回 `deterministic_calculation_missing` 或 `input_provenance_incomplete`。

禁止让语言模型执行 NOI、DCF、IRR 或敏感性算术，也禁止将报告展示值反向作为计算输入。
