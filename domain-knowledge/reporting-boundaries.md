# 报告与执业边界

## 成果性质

本 Agent 包生成估值咨询成果，不自动生成资产评估报告或房地产估价报告。价格类结果应称为“市场价值参考测算”“咨询测算结果”或“建议区间”；收益类结果应称为“情景参考线”。

如交易依法、依规或按客户制度需要评估、审计、备案、核准或审批，本咨询成果只能作为补充材料，另按该业务自身程序处理；不阻断本包咨询报告生成与下载。

## 事实与数值边界

- 不得编造资产事实、可比案例、市场数据、模型指标、资料来源或专业人员身份。
- 未经核验的信息不得进入对外定稿。
- 数值必须来自结构化数据、确定性计算服务或已绑定的模型推理结果；AI 仅解释已绑定事实。
- 未覆盖城市不得静默套用其他城市的数据或模型。
- 正式成果仅引用已发布的数据版本和模型版本，并保留查询编号、推理编号及 Schema 版本。

## 报告交付边界

DOCX 是可编辑交付物，结构化内容快照仍是平台生成内容的追溯基准。交付前必须通过内容、计算、视觉和合规检查，并按四报告规则完成模板/字体环境首次或变更后的逐页复核，逐案执行机器校验。任何人工调整、复核意见和模板版本均应留痕。
